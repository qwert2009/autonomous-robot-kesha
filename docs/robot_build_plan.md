## ВАРИАНТ 1: Полностью локальный ИИ (рекомендуемый)

Робот подключается по Wi-Fi к твоему ПК (RTX 3050, 16GB RAM), где крутятся все ИИ-модели. ПК выступает как локальный API-сервер.

|--------|--------|----------|------|
| **LLM** (мозг) | Ollama + Llama 3.1 8B (Q4) | ~5GB VRAM | :11434 |
| **TTS** (голос) | Piper TTS (русский) | ~200MB RAM | :5500 |

| **Computer Vision** | YOLOv8n (nano) | ~1GB VRAM | :5700 |

**Итого VRAM**: ~7-8 GB (RTX 3050 = 8GB — впритык, но работает)

## Архитектура системы

```
[РОБОТ: ESP32-CAM]              [ПК: RTX 3050]
┌─────────────────┐              ┌──────────────────────┐
│ Камера OV2640   │    Wi-Fi     │ Ollama (LLM)  :11434 │
│ Микрофон INMP441│ ◄═══════► │ Whisper (STT) :5600  │
│ Динамик+PAM8403 │   HTTP/WS   │ Piper (TTS)   :5500  │
│ 2x TT мотор     │              │ YOLOv8 (CV)   :5700  │
│ HC-SR04 + IR     │              │ FastAPI        :8000  │
│ MPU6050          │              │                      │
│ LM2596 → 5V     │              │ GPU: 8GB VRAM        │
│ 3x18650 (BMS)   │              │ RAM: ~8GB свободно   │
└─────────────────┘              └──────────────────────┘
```

### Поток данных:
1. ESP32-CAM захватывает кадр → POST на ПК `/api/vision`
2. Микрофон записывает аудио → POST на ПК `/api/stt`
3. ПК распознаёт речь → отправляет текст в LLM → получает ответ
4. Ответ LLM → TTS на ПК → аудио обратно на ESP32
5. ESP32 воспроизводит через PAM8403 + динамик
6. LLM решает куда ехать → команда моторам через L298N

## Настройка ПК как локального API-сервера

### 1. Установка Ollama (LLM)
```bash
curl -fsSL https://ollama.com/install.sh | sh
ollama pull llama3.1:8b-instruct-q4_K_M
# API автоматически на http://localhost:11434
```

### 2. Установка Faster-Whisper (STT)
```bash
pip install faster-whisper fastapi uvicorn
```

### 3. Установка Piper TTS
```bash
pip install piper-tts
# Скачать русскую модель:
# https://github.com/rhasspy/piper/releases — ru_RU-ruslan-medium
```

### 4. Установка YOLOv8 (Computer Vision)
```bash
pip install ultralytics fastapi uvicorn python-multipart
```
