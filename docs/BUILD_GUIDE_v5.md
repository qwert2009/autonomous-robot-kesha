## 3. Сборка шасси

### Шаг 1: Подготовка платформы
1. Возьми **4WD акриловое шасси** (2 пластины: верх и низ)
2. Открути защитную плёнку с акрила

### Шаг 2: Установка моторов
1. Закрепи **4 TT мотора** в штатные крепления на **нижней** пластине
2. Расположение (вид сверху):
```
       ПЕРЕД
  ┌─────────────┐
  │ FL       FR │   FL = Front-Left, FR = Front-Right
  │             │
  │ BL       BR │   BL = Back-Left,  BR = Back-Right
  └─────────────┘
       ЗАД
```
3. Используй винты M3×25 + гайки M3 для крепления моторов
4. Провода моторов: выведи по 2 провода от каждого мотора (красный +, чёрный −)
5. **Подпиши провода!** FL, FR, BL, BR — чтобы не перепутать

### Шаг 3: Установка Mecanum колёс
1. Mecanum колёса имеют **направление** — ролики под 45°
2. Правильное расположение (вид сверху — ролики образуют **X**):
```
       ПЕРЕД
  ╲           ╱    ← ролики наклонены ВНУТРЬ
  ╱           ╲    ← ролики наклонены НАРУЖУ
       ЗАД
```
3. Если вид сверху — ролики образуют букву **X** (а не O) — ты всё правильно сделал
4. Насади колёса на валы моторов, зафиксируй винтом

### Шаг 4: Стойки
1. Вкрути **4 латунные стойки M3×30** по углам нижней пластины
2. На них ляжет верхняя пластина (позже)

## 4. ESP32-WROOM — Тело робота

### Распиновка (из robot_firmware_v5_drive.ino)

```
ESP32-WROOM-32 DevKit
┌─────────────────────────────────────┐
│                                     │
│  GPIO25 ─── MX1508 #1 IN1 ──→ FL+  │
│  GPIO26 ─── MX1508 #1 IN2 ──→ FL−  │
│  GPIO27 ─── MX1508 #1 IN3 ──→ FR+  │
│  GPIO14 ─── MX1508 #1 IN4 ──→ FR−  │
│                                     │
│  GPIO33 ─── MX1508 #2 IN1 ──→ BL+  │
│  GPIO32 ─── MX1508 #2 IN2 ──→ BL−  │
│  GPIO23 ─── MX1508 #2 IN3 ──→ BR+  │
│  GPIO22 ─── MX1508 #2 IN4 ──→ BR−  │
│                                     │
│  GPIO18 ─── HC-SR04 #1 TRIG (перед)│
│  GPIO19 ─── HC-SR04 #1 ECHO (перед)│
│  GPIO21 ─── HC-SR04 #2 ECHO (зад)  │
│  (TRIG зад = тот же GPIO18)         │
│                                     │
│  GPIO34 ─── E18 левый (input only)  │
│  GPIO35 ─── E18 правый (input only) │
│                                     │
│  GPIO17 ─── SG90 серво (сигнал)     │
│                                     │
│  GPIO36 ─── BAT_ADC (делитель)      │
│  GPIO39 ─── DOCK_ADC (контакт дока) │
│                                     │
│  GPIO4  ─── UART TX → ESP32-CAM RX  │
│  GPIO16 ─── UART RX ← ESP32-CAM TX  │
│                                     │
│  VIN ←── 5В от LM2596              │
│  GND ←── общий GND                  │
└─────────────────────────────────────┘
```

### Пошаговая разводка

#### MX1508 #1 (передние колёса FL + FR):
1. Подключи питание MX1508: **VCC → батарея 11.1В**, **GND → общий GND**
2. **IN1 → GPIO25**, **IN2 → GPIO26** — мотор FL (передний левый)
3. **IN3 → GPIO27**, **IN4 → GPIO14** — мотор FR (передний правый)
4. **OUT1/OUT2** → провода FL мотора, **OUT3/OUT4** → провода FR мотора

#### MX1508 #2 (задние колёса BL + BR):
1. Подключи питание: **VCC → батарея 11.1В**, **GND → общий GND**
2. **IN1 → GPIO33**, **IN2 → GPIO32** — мотор BL (задний левый)
3. **IN3 → GPIO23**, **IN4 → GPIO22** — мотор BR (задний правый)
4. **OUT1/OUT2** → BL мотор, **OUT3/OUT4** → BR мотор

> ⚠ **ВНИМАНИЕ:** Если колесо крутится не в ту сторону — просто **поменяй местами 2 провода** мотора (или OUT1/OUT2 на MX1508). НЕ меняй код!

#### HC-SR04 #1 (перед):
1. **VCC → 5В**, **GND → GND**
2. **TRIG → GPIO18**, **ECHO → GPIO19**
3. Расположи сенсор в **центре переднего бампера**, ультразвук смотрит вперёд

#### HC-SR04 #2 (зад):
1. **VCC → 5В**, **GND → GND**
2. **TRIG → GPIO18** (общий с передним!), **ECHO → GPIO21**
3. Расположи на **заднем бампере**, ультразвук смотрит назад

#### E18-D80NK (ИК-датчики бортов):
1. **Коричневый → GND**, **Синий → 5В**, **Чёрный → сигнал**
2. E18 левый: Чёрный → **GPIO34**
3. E18 правый: Чёрный → **GPIO35**
4. Закрепи на **левом и правом борту**, направлены вниз и в сторону (обрыв стола / стена)

#### SG90 серво (голова):
1. **Красный → 5В**, **Коричневый → GND**, **Оранжевый → GPIO17**
2. Закрепи на верхней пластине, на серво установи ESP32-CAM

#### Делитель напряжения для BAT_ADC (GPIO36):
```
Батарея 11.1В ──[R1=20кОм]──┬──[R2=10кОм]──GND
                              │
                           GPIO36
```
- Соотношение 2:1, максимум на ADC = 3.67В при полном заряде (12.6В)
- ESP32 ADC = 0-3.3В, 12-bit (0-4095)

#### Контакт дока (DOCK_ADC = GPIO39):
```
Медная пластина (на днище робота) ──[R=10кОм]──┬──GND
                                                  │
                                               GPIO39
```
- Когда робот на зарядке: напряжение от станции подтягивает GPIO39 вверх
- Без контакта: pull-down через 10кОм = 0В

## 5. ESP32-CAM — Мозг робота

### Распиновка (из robot_firmware_v5_cam.ino)

```
ESP32-CAM (AI-Thinker)
┌─────────────────────────────────────┐
│                                     │
│  ╔═══ КАМЕРА OV2640 (встроена) ═══╗ │
│  ║ AI-Thinker стандартная разводка ║ │
│  ╚═════════════════════════════════╝ │
│                                     │
│  ╔═══ I2S МИКРОФОН (INMP441) ═════╗ │
│  ║ BCLK  → GPIO14                 ║ │
│  ║ WS    → GPIO15                 ║ │
│  ║ DOUT  → GPIO12  ← микрофон!    ║ │
│  ╚═════════════════════════════════╝ │
│                                     │
│  ╔═══ I2S УСИЛИТЕЛЬ (MAX98357A) ══╗ │
│  ║ BCLK  → GPIO14  (общий)       ║ │
│  ║ WS    → GPIO15  (общий)       ║ │
│  ║ DIN   → GPIO2   ← динамик!    ║ │
│  ╚═════════════════════════════════╝ │
│                                     │
│  GPIO13 → UART TX → ESP32-WROOM RX │
│  GPIO4  ← UART RX ← ESP32-WROOM TX│
│                                     │
│  GPIO3  → WS2812B (LED эмоций)     │
│                                     │
│  3.3V ← AMS1117 ← 5В от LM2596   │
│  GND  ← общий GND                  │
└─────────────────────────────────────┘
```

### ⚠ КРИТИЧЕСКИ ВАЖНО: GPIO12 pulldown
**GPIO12** на ESP32-CAM управляет flash voltage:
- Если GPIO12 = HIGH при загрузке → ESP32 не стартует!
- **Припаяй 10кОм между GPIO12 и GND**
- Это не мешает работе INMP441 (I2S данные AC-coupled)

### Подключение INMP441 (I2S микрофон):
```
INMP441          ESP32-CAM
───────          ─────────
VDD     →       3.3В
GND     →       GND
SCK     →       GPIO14 (BCLK)
WS      →       GPIO15 (Word Select)
SD      →       GPIO12 (Data Out) + 10кОм pull-down к GND!
L/R     →       GND (выбираем левый канал)
```

### Подключение MAX98357A (I2S усилитель → динамик):
```
MAX98357A        ESP32-CAM
─────────        ─────────
VIN      →       5В (от LM2596, НЕ от 3.3В!)
GND      →       GND
BCLK     →       GPIO14 (общий с INMP441)
LRC      →       GPIO15 (общий с INMP441)
DIN      →       GPIO2  (Data In)
GAIN     →       не подключать (15dB по умолчанию)
SD (shutdown) →  не подключать (active по умолчанию)
```
- К выходу MAX98357A подключи **динамик 4Ω 3W** (+ и −)

### WS2812B LED (индикатор эмоций):
```
WS2812B          ESP32-CAM
───────          ─────────
VCC     →       5В
GND     →       GND
DIN     →       GPIO3 (через резистор 330Ω)
```

## 6. UART-мост между ESP32

### Физическое соединение:
```
ESP32-CAM GPIO13 (TX)  ─────→  ESP32-WROOM GPIO16 (RX)
ESP32-CAM GPIO4  (RX)  ←─────  ESP32-WROOM GPIO4  (TX)
GND (CAM)              ─────→  GND (WROOM) — ОБЯЗАТЕЛЬНО!
```

### Параметры: 115200 бод, 8N1

### Протокол команд (CAM → WROOM):
| Команда | Формат | Пример | Действие |
|---------|--------|--------|----------|
| Move | `M:vy,vx,omega\n` | `M:150,0,0\n` | Вперёд speed=150 |
| Wheels | `W:fl,fr,bl,br\n` | `W:200,-200,200,-200\n` | Краб вправо |
| Servo | `S:angle\n` | `S:90\n` | Голова прямо |
| Dock | `D:1\n` / `D:0\n` | `D:1\n` | Начать/отменить стыковку |
| Query | `?\n` | `?\n` | Запросить состояние датчиков |

### Ответы (WROOM → CAM):
```
S:df,db,il,ir,bat,dock,heading
```
Пример: `S:45.2,120.0,0,1,78,0,90.5`
- df = расстояние перед (см)
- db = расстояние зад (см)
- il = ИК левый (0/1)
- ir = ИК правый (0/1)
- bat = заряд батареи (%)
- dock = контакт дока (0/1)
- heading = направление IMU (°)

## 7. Батарейная система

### Схема питания:
```
3x 18650 (в боксе) ─── BMS 3S 20A ─── Выключатель
                                            │
                     ┌──────────────────────┘
                     │ 11.1В
                     ├──→ MX1508 #1 VCC (моторы FL, FR)
                     ├──→ MX1508 #2 VCC (моторы BL, BR)
                     │
                     └──→ LM2596 #1 (вход)
                          │
                          └── 5В (выход)
                              ├──→ ESP32-WROOM VIN
                              ├──→ HC-SR04 x2 VCC
                              ├──→ E18 x2 VCC
                              ├──→ SG90 VCC
                              ├──→ MAX98357A VIN
                              ├──→ WS2812B VCC
                              │
                              └──→ AMS1117 (вход)
                                   │
                                   └── 3.3В (выход)
                                       ├──→ ESP32-CAM 3V3
                                       └──→ INMP441 VDD
```

### Настройка LM2596:
1. **БЕЗ нагрузки** подключи вход к 12В (или батарее)
2. Крути **потенциометр** маленькой отвёрткой
3. Мультиметром на выходе выставь **точно 5.0В**
4. Подключи нагрузку — проверь что не просело ниже 4.8В

### Расчёт автономности:
- 3× 18650 3200mAh = 3200mAh × 11.1В = **35.5 Вт·ч**
- Потребление в движении: ~2-3A при 11.1В ≈ **25-33 Вт**
- Потребление в простое: ~0.5A ≈ **5.5 Вт**
- **В движении: ~1-1.5 часа**
- **В простое: ~6-7 часов**

## 8. Зарядная станция (док)

### Компоненты станции:
| Деталь | Назначение |
|--------|------------|
| Блок питания 12В 2A | Вход |
| LM2596 #2 | Выставить **12.6В** (напряжение зарядки 3S) |
| 2× медные пластины 30×10мм | Контактные площадки |
| Картон / пластик / 3D-печать | Корпус станции |
| V-образные направляющие | Чтобы робот сам заезжал ровно |
| Резистор 10кОм | Pull-down для определения контакта |

### Схема станции:
```
Блок питания 12В 2A
        │
   LM2596 #2 (выставить 12.6В!)
        │
  ┌─────┴─────┐
  │  + контакт │──── Медная пластина LEFT (+)
  │  − контакт │──── Медная пластина RIGHT (−)
  └───────────┘

  На роботе (снизу):
  ┌───────────────────────┐
  │ Медная LEFT  → BMS P+ │  (через диод Шоттки 1N5822 или без)
  │ Медная RIGHT → BMS P− │
  │ Медная LEFT  → GPIO39 │  (через 20кОм делитель для определения)
  └───────────────────────┘
```

### Сборка V-направляющих:
```
  Вид сверху станции:

       ╱─────────╲
      ╱    РОБОТ   ╲        ← V-образные стенки наводят
     ╱   заезжает   ╲          робота в центр
    ╱    задом        ╲
   ║                   ║
   ║  [Cu+]    [Cu−]  ║     ← медные контакты на дне
   ║                   ║
   ╚═══════════════════╝     ← задняя стенка = упор
```

### Алгоритм автостыковки (robot_firmware_v5_drive.ino):
1. **Фаза 0** (SEARCH): Робот ищет станцию — едет к запомненным координатам
2. **Фаза 1** (ALIGN): Разворачивается задом к станции (HC-SR04 зад)
3. **Фаза 2** (APPROACH): Медленно сдаёт назад (speed=80)
4. **Фаза 3** (CONTACT): HC-SR04 зад < 5см → остановка, проверка ADC GPIO39
5. **Фаза 4** (DOCKED): Напряжение на GPIO39 > порога → заряжаюсь!

### Настройка LM2596 #2 (для станции):
1. Вход: 12В от блока питания
2. Крути потенциометр — выставь **12.6В** на выходе (напряжение полного заряда 3S)
3. BMS сама контролирует ток и отсечку — LM2596 просто даёт напряжение
4. **ПРОВЕРЬ**: когда батареи полные — BMS отключает зарядку, ток = 0

> ⚠ Ток зарядки зависит от BMS. BMS 3S 20A обычно ограничивает зарядку до 1-2A.
> С 3200mAh батареями полная зарядка = ~2-3 часа.

## 9. Финальная сборка

### Порядок:
1. **Нижняя пластина**: моторы + колёса + MX1508 ×2 + бокс с 18650 + BMS
2. **Средний слой**: ESP32-WROOM + макетная плата + LM2596 + выключатель
3. **Верхняя пластина**: SG90 серво + ESP32-CAM + INMP441 + MAX98357A + динамик + WS2812B
4. **Контакты зарядки**: 2 медные полоски на днище (сзади!)

### Крепление ESP32-CAM на серво:
1. Приклей ESP32-CAM к качалке серво (камерой вперёд)
2. Серво крутит голову (0°=лево, 90°=прямо, 180°=право)

### Кабель-менеджмент:
- Протяни UART-провода (3 шт: TX, RX, GND) между этажами
- Используй стяжки для пучков проводов
- Оставь слабину — серво крутит голову!

### Расположение датчиков:
```
           ПЕРЕД
    ┌─────────────────┐
```

## 10. Прошивка и запуск

### Шаг 1: Прошить ESP32-WROOM
1. Открой Arduino IDE (или PlatformIO)
2. Установи плату: **ESP32 Dev Module**
3. Открой `firmware/robot_firmware_v5_drive.ino`
4. Параметры:
   - Board: ESP32 Dev Module
   - Upload Speed: 921600
   - Flash Frequency: 80MHz
   - Partition: Default 4MB
5. Подключи ESP32-WROOM по USB → Upload

### Шаг 2: Прошить ESP32-CAM
1. ESP32-CAM **не имеет USB** → используй USB-TTL переходник:
   ```
   USB-TTL     ESP32-CAM
   ───────     ─────────
   TX    →     U0R (GPIO3)
   RX    →     U0T (GPIO1)
   GND   →     GND
   5V    →     5V
   ```
2. **Для прошивки**: соедини **GPIO0 → GND** (перемычка!)
3. Открой `firmware/robot_firmware_v5_cam.ino`
4. Параметры:
   - Board: **AI Thinker ESP32-CAM**
   - Upload Speed: 115200
   - Partition: Huge APP (3MB No OTA)
5. Upload → после загрузки **убери перемычку GPIO0-GND**
6. Нажми Reset → ESP32-CAM запустится

### Шаг 3: WiFi
1. В `robot_firmware_v5_cam.ino` поставь свой WiFi:
   ```cpp
   const char* ssid = "ТВОЯ_СЕТЬ";
   const char* password = "ТВОЙ_ПАРОЛЬ";
   const char* serverUrl = "http://IP_ТВОЕГО_ПК:8000";
   ```
2. IP ПК: открой cmd → `ipconfig` → IPv4 адрес

### Шаг 4: Запуск ПК-сервера
1. Двойной клик на `start_kesha.bat`
2. Ollama запустится → загрузит dolphin-llama3:8b
3. FastAPI сервер стартанёт на **http://0.0.0.0:8000**
4. Проверь: открой `http://localhost:8000/docs` в браузере

### Шаг 5: Первый запуск!
1. Включи питание робота (выключатель)
2. ESP32-CAM подключится к WiFi → к серверу
3. WROOM отрапортует датчики через UART
4. **Кеша скажет первые слова!** (first_launch = true)

## 11. Диагностика

### Мотор не крутится:
- Проверь питание MX1508 (11.1В на VCC)
- Проверь GPIO: `analogWrite(GPIO25, 200)` в Serial Monitor
- Поменяй провода мотора местами если крутит не туда

### Нет звука:
- MAX98357A нужен **5В** (не 3.3В!)
- Проверь GPIO2 (DIN) — не занят ли чем-то ещё
- Попробуй: `i2s_write()` тестовый tone 1kHz

### ESP32-CAM не стартует:
- GPIO12 pull-down к GND (10кОм) — **обязательно!**
- Не хватает тока по USB → подключи внешние 5В
- Убери перемычку GPIO0-GND после прошивки!

### UART не работает:
- Проверь скрещивание: TX одного → RX другого
- **Общий GND обязателен!**
- В Serial Monitor: 115200 бод
- Отправь `?\n` → должен получить `S:...`

### Автодок не работает:
- Проверь что медные контакты чистые (нет окисла)
- Проверь ADC GPIO39: в Serial Monitor посмотри значение
- Без контакта: ~0, с контактом: >1000 (из 4095)
- V-направляющие должны быть гладкими — робот должен скользить

### WiFi отваливается:
- Проверь что ПК и робот в одной сети
- Убери `sleep mode`: `WiFi.setSleep(false);`
- Попробуй статический IP в коде вместо DHCP
